# Faceless Shorts Pack

Ten complete, fully written faceless short scripts across ten niches — plus the
overlay layouts, b-roll lists, narration guide, and a 30-day posting plan around them.
Everything is text-first: no face, no camera operator, no on-location crew. Read a
script, record the voiceover, lay the text over footage, post.

## Use the whole pack in a day

**Morning (2 hours) — write nothing, record everything:**
1. Pick 5 scripts (one per weekday lane).
2. Read each narration once aloud, trim to its word budget (`voiceover.md` pacing table).
3. Record all 5 voiceovers back-to-back in one room — 40 minutes.

**Midday (2.5 hours) — footage:**
4. Pull b-roll from `b-roll.md` Part 1 shot list (search terms included) or film your own hands/desk shots — the recipe in Part 2.
5. Log clips by scene number, one bin per script.

**Afternoon (3 hours) — edit:**
6. Set your editor preset once: 1080×1920, 30 fps, H.264.
7. Build script 1 end to end using its scene table: drop VO, cut to beat times, paste on-screen text using one layout per beat from `templates.md`.
8. Copy the project as a template — scripts 2–5 become swap-and-go.

**Evening (45 minutes) — ship:**
9. Export, run the checklist in `posting.md`'s weekly rhythm, write captions (or adapt the three-variant system in your own notes), schedule the first post.
10. Fill in `posting.md`'s schedule rows so the week runs itself.

You now have five videos for five days. Next week's batch takes about half the time.

## Tool suggestions

| Task | Free option | Paid option |
|---|---|---|
| Editing | **CapCut** (desktop or phone), **DaVinci Resolve** | Premiere Pro, Final Cut |
| Voiceover | **GarageBand / Windows Voice Recorder** + a closet for treatment | Shure MV7, Rode NT-USB Mini |
| Text overlays | CapCut text presets; set them once, duplicate per scene | Motion templates in your NLE |
| B-roll & stills | **Pexels, Pixabay, Mixkit, Coverr** (licenses in `b-roll.md`) | Storyblocks, Artgrid |
| Music & SFX | **YouTube Audio Library**, in-app Commercial Music Library | Epidemic Sound, Artlist |
| Screen capture | **OBS Studio** (free, open source) | — |
| Captions | Auto-captions in CapCut/YouTube, corrected by hand | — |
| Thumbnail / cover | **Canva** free tier | Canva Pro |

Free tools are genuinely enough for every video in this pack — the paid column exists
only so you know what upgrades are for, and none of them are needed in month one.
